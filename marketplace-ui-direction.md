# Just Finds Marketplace UI Direction

## Product posture

Just Finds will feel like a practical local marketplace on the public side and focused business software inside authenticated workspaces. The interface borrows broad interaction patterns—fast browsing, visible categories, prominent actions, touch-first cards, and dense operational summaries—from modern local-discovery and productivity products, while retaining an original Just Finds identity.

## Original public experience

| Pattern | Just Finds implementation |
| --- | --- |
| Discovery | Search first, followed by horizontal category chips, compact local-result cards, proximity/context labels, and clear Call, Book, Quote, or View actions only where available. |
| Visual identity | Ink-blue foundation, warm white content canvas, signal-blue interactions, and a restrained location coral. Typography remains distinct from the referenced brands. |
| Listing cards | One useful visual/data focal point, verified or availability signals when factual, compact service/category metadata, and a direct next step. |
| Mobile app behavior | Persistent five-item bottom navigation, thumb-reachable primary actions, scrollable chips, bottom-sheet-compatible spacing, and safe-area-aware page endings. |

## Original owner and admin software experience

| Pattern | Just Finds implementation |
| --- | --- |
| Dashboard density | Summary metrics, current-state badges, priority task cards, and visible next actions rather than decorative panels. |
| Navigation | Purposeful dark workspace rail on desktop; compact menu with persistent mobile controls on smaller screens. |
| Forms | Larger touch targets, grouped field sections, sticky save/action zones where supported, and inline factual validation. |
| Data integrity | No fake ratings, reviews, testimonials, business data, analytics, or listings. Interfaces show empty states when real data is unavailable. |

## Responsive commitment

The site will be **fully responsive**, with an app-like mobile interface rather than a reduced desktop layout. Mobile remains a first-class experience at 375px and above; desktop retains efficient multi-column data and governance layouts.

## Explicit boundaries

Just Finds will not copy the branding, logos, source code, proprietary assets, typography, layouts, or trade dress of Swiggy, Zomato, Microsoft, Apple, Google, or Justdial. The implementation uses original CSS, existing project components, real Just Finds data, and the project’s own compass mark.
